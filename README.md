# Portal de Implantação – Cittati

Painel web da equipe de implantação da Cittati.

**Acesso:** https://braytinersanches.github.io/implantacao/

## Módulos
- **Implantações:** acompanhamento das atividades de implantação por cliente.
- **Entregas para Suporte:** formulário de entrega da implantação para o suporte, com download em PDF e imagem.
- **Usuários:** gestão de acessos (somente administradores).

## Estrutura
- `index.html`: o painel completo (HTML, CSS e JavaScript).
- Banco de dados e login: Supabase.

O acesso exige usuário e senha cadastrados por um administrador.
